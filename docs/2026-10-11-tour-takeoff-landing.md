## 5. 동작 (`-54`)

### 5.1 이륙
1. 바닥에서 CH6 **AUTO** 로 둔다. 보드는 `GROUND`(스로틀 1000) 상태로 기다린다.
2. 시동을 건다. 스로틀이 150µs/s 로, 호버 추정(처음 1510, 이후 배운 값) −80µs 부터는 50µs/s 로 오른다.
3. 센서가 7cm 를 넘거나 8cm/s 넘게 오르면 떠오른 것으로 본다. 이때부터 상승 속도를 제어한다 (`-57`).
   - 높이별 호버 감소(착륙과 같은 조종자 실측 곡선)를 미리 뺀다.
   - 60cm 아래는 35cm/s, 위는 25cm/s 로 오른다. 60cm 아래는 태그가 늦게 잡혀 수평 제어가 없는 구간이라 빨리 지난다.
   - 120cm 가까이에서는 남은 거리 × 1/s 로 줄인다. ±3cm 안에서 6cm/s 아래로 멈추면 유지로 넘긴다.
   - 떠오른 순간 넘친 스로틀은 평소의 3배 속도로 내린다.
4. 호버 추정 +60µs 에서 1.5초 기다려도 안 뜨면 중단하고 1000 으로 돌아간다 (`takeoff_fail`).
5. 이륙이 끝나 고도 유지에 들어간 뒤에만 투어가 시작된다. 이륙 중에는 태그 위에 머물기만 한다.

### 5.2 왕복 미션 (투어 `mode 1`, 기본)

| 단계 | 태그 | 머무름 | 다음 |
|---|---|---|---|
| 1 | A (이륙 태그) | 3초 | 앞으로 |
| 2 | B | 3초 | 뒤로 |
| 3 | A | 5초 | 앞으로 |
| 4 | B | 3초 | 착륙 |

- A 는 이륙 중 처음 본 태그다. 이륙 뒤 10초 동안은 A 만 찾는다 (`-52`).
- "앞"은 A 에서 기수를 맞춘 뒤의 기수 방향이다. 이동 중에도 이 기수를 유지하고, 뒤로 갈 때는 돌지 않고 후진한다.
- 다음 태그는 떠나온 태그가 아니고, 진행 방향 ±45° 안에 있으며, 연속 2프레임 보여야 인정한다.
- 머무름 시간은 태그가 보이고 중심에서 25cm 안일 때만 센다.

태그 사이는 칼만 예측 대신 조종자처럼 정해진 기울기로 간다 (`-53`, `-54`).

| 구간 | 기울기 | 시간 |
|---|---|---|
| 가속 | 2.0° | 0.8초 |
| 유지 | 0.6° | 다음 태그가 보일 때까지, 최대 5초 |
| 제동 (다음 태그 보임) | 반대로 2.5° | 0.6초 → 칼만 처음부터, 태그 위 제어 |
| 5초 안에 안 보임 | 제동 뒤 반대로 같은 기울기 | 떠난 태그가 보이면 제동 → 대기(DONE). 10초 넘으면 LOST(보드 중립) |

- 이동 기울기 위에 수평 유지 보정(trim)을 더한다 (`-56`).
  - 보정값은 태그 위에서 칼만이 추정한 외란 가속도 b 를 지우는 기울기다.
  - 비행 기록(`-51`~`-53`)에서 이 값은 태그 위 명령 중앙값과 12µs 안으로 맞았다.
  - `-53` 까지는 머무름 3초 동안 명령을 평균해 다가오며 낸 명령이 섞였다. 그래서 B 에서 +34µs(실제 −6µs)가 나와 뒤로 가는 기울기를 지웠다.
- 이동 중에는 매 프레임 전체 화면에서 태그를 찾는다 (`-56`). 8cm 태그를 120cm 에서 찾느라 한 장에 약 0.45초 걸린다.
- 다음 태그는 진행 방향 안에서 **한 장만** 보여도 인정한다 (`-56`). `-53` 첫 시도에서 B 를 한 장만 보고 지나쳤다.
- PC 시험 이동 최고 속도는 22~24cm/s 다 (`-53` 실제 앞 이동 약 26cm/s, 조종자 25~40cm/s).

### 5.3 자동 착륙

**착륙이 시작되는 조건** (하나라도 맞으면 착륙 요청)
- 왕복 미션 마지막 단계(4번째 태그 B)에서 머무름을 마침.
- 다음 태그를 못 찾아 떠난 태그 위에서 대기(DONE)한 지 10초 (`-54`, `tour set stuck_land_ms`). `-53` 비행은 이 조건이 없어 A 위에서 대기만 하고 착륙하지 않았다.
- `alt land` 명령 (뷰어 `l`).

착륙 요청은 고도 오류(`alt_error`)보다 우선한다 (`-54`).

1. **40cm 위:** 10cm/s 로 하강한다. 착륙 시작 높이에 대한 호버 감소(40cm 위 0.45µs/cm, 아래 1.1µs/cm)를 미리 뺀다.
2. **40cm 아래:** 5cm/s 로 내려간다.
3. **20cm:** 스로틀을 45µs 내리고 내려앉기를 기다린다. 3초 안에 안 닿으면 초당 10µs 씩 더 내린다.
4. **착지:** 25cm 아래에서 센서 값이 4cm 이하(또는 최소 거리 아래)인 표본이 1초 안에 2번이면 바로 스로틀 1000 으로 내리고, 수동 전환까지 유지한다. INAV 가 시동을 끈다.

수평은 이렇게 다룬다.
- 태그는 50cm 아래에서 안 보인다(너무 가까움). 그 뒤로는 칼만 예측으로 그 자리를 유지한다.
- 15cm 아래와 착지 뒤에는 롤·피치·요가 중립이다.

### 5.4 명령

| 명령 | 뜻 |
|---|---|
| `tour on/off/params/set <k> <v>` | `mode`(0 화살표, 1 왕복), `ol_accel`, `ol_cruise`, `ol_brake`, `stuck_land_ms`, `land_at` 등 |
| `alt` / `alt params` / `alt set <k> <v>` | `takeoff`(0/1), `takeoff_height`, `land_rate`, `land_settle_drop`, `abort_err`, `abort_ms` 등 |
| `alt land` / `alt cancel` / `alt target <cm>` | 착륙 / 착륙 취소 / 유지 목표 |
| `exp fast` / `exp auto` | 짧은 노출 / 자동 노출 (`-53`부터 기본은 자동. 짧은 노출은 인식이 4fps 로 느려짐) |

뷰어 키는 다음과 같다.
- `t`: 투어
- `l`: 착륙
- `v`: 좌표/영상

오른쪽 위에 고도, 왼쪽에 투어·고도 상태가 나온다.

## 6. PC 시험 (`test/tour_host_test.cpp`, `test/alt_hold_host_test.cpp`)

모든 시험의 기체 모델은 조종자 실측 높이별 호버 곡선(0.6~1.5배)이다. 공통 조건은 다음과 같다.
- 추력 민감도 1~5cm/s²/µs
- 거리센서 지연 0.1~0.25s
- 센서 튀는 값 5%
- 10cm 아래에서 센서 최소 거리 아래 값 70%

| 시험 | 결과 |
