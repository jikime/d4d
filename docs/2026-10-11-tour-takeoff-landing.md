# 태그 투어·이륙·고도 유지·자동 착륙 — 펌웨어 `-41`~`-50`

2026-10-11 작업이다. 이전 단계는 [WiFi·칼만·좌표 모드](2026-10-11-wifi-kf-coords-flight.md)(`-35`~`-40`)다. 이번 단계에서 태그 투어, 보드 스로틀(고도 유지·이륙·착륙)을 붙였다. 보드에 올라간 버전은 `TAGVISION-20261011-50`(업로드 대기)이다.

## 2. FC 설정 (읽기만 확인, 바꾸지 않음)

| 설정 | 값 | 뜻 |

## 5. 동작 (`-50`)

### 5.1 이륙
1. 바닥에서 CH6 **AUTO** 로 둔다. 보드는 `GROUND`(스로틀 1000) 상태로 기다린다.
2. 시동을 건다. 스로틀이 150µs/s 로, 호버 추정(처음 1510, 이후 배운 값) −80µs 부터는 50µs/s 로 오른다.
3. 센서가 7cm 를 넘거나 8cm/s 넘게 오르면 떠오른 것으로 본다. 이때부터 목표를 25cm/s 로 올려 120cm 에서 유지한다.
4. 호버 추정 +60µs 에서 1.5초 기다려도 안 뜨면 중단하고 1000 으로 돌아간다 (`takeoff_fail`).
5. 이륙이 끝나 고도 유지에 들어간 뒤에만 투어가 시작된다. 이륙 중에는 태그 위에 머물기만 한다.

### 5.2 왕복 미션 (투어 `mode 1`, 기본)

| 단계 | 태그 | 머무름 | 다음 |
|---|---|---|---|
| 1 | A (처음 본 태그) | 10초 | 앞으로 |
| 2 | B | 10초 | 뒤로 |
| 3 | A | 5초 | 앞으로 |
| 4 | B | 5초 | 착륙 |

- "앞"은 A 에서 기수를 맞춘 뒤의 기수 방향이다. 이동 중에도 이 기수를 유지하고, 뒤로 갈 때는 돌지 않고 후진한다.
- 다음 태그는 떠나온 태그가 아니고, 진행 방향 ±45° 안에 있으며, 연속 2프레임 보여야 인정한다.
- 80cm 를 가도 다음 태그가 없으면 떠난 태그로 돌아가 머문다.
- 머무름 시간은 태그가 보이고 중심에서 25cm 안일 때만 센다.

### 5.3 자동 착륙
1. **40cm 위:** 10cm/s 로 하강한다. 착륙 시작 높이에 대한 호버 감소(40cm 위 0.45µs/cm, 아래 1.1µs/cm)를 미리 뺀다.
2. **40cm 아래:** 5cm/s 로 내려간다.
3. **20cm:** 스로틀을 45µs 내리고 내려앉기를 기다린다. 3초 안에 안 닿으면 초당 10µs 씩 더 내린다.
4. **착지:** 25cm 아래에서 센서 값이 4cm 이하(또는 최소 거리 아래)인 표본이 1초 안에 2번이면 바로 스로틀 1000 으로 내리고, 수동 전환까지 유지한다. INAV 가 시동을 끈다.

수평은 이렇게 다룬다.
- 태그는 50cm 아래에서 안 보인다(너무 가까움). 그 뒤로는 칼만 예측으로 그 자리를 유지한다.
- 15cm 아래와 착지 뒤에는 롤·피치·요가 중립이다.

### 5.4 명령

| 명령 | 뜻 |
|---|---|
| `tour on/off/params/set <k> <v>` | `mode`(0 화살표, 1 왕복), `speed`, `dist`, `land_at` 등 |
| `alt` / `alt params` / `alt set <k> <v>` | `takeoff`(0/1), `takeoff_height`, `land_rate`, `land_settle_drop` 등 |
| `alt land` / `alt cancel` / `alt target <cm>` | 착륙 / 착륙 취소 / 유지 목표 |
| `exp auto` | 짧은 노출(기본)을 자동 노출로 |

뷰어 키는 다음과 같다.
- `t`: 투어
- `l`: 착륙
- `v`: 좌표/영상

오른쪽 위에 고도, 왼쪽에 투어·고도 상태가 나온다.

## 6. PC 시험 (`test/tour_host_test.cpp`, `test/alt_hold_host_test.cpp`)

모든 시험의 기체 모델은 조종자 실측 높이별 호버 곡선(0.6~1.5배)이다. 공통 조건은 다음과 같다.
- 추력 민감도 1~5cm/s²/µs
- 거리센서 지연 0.1~0.25s
- 센서 튀는 값 5%
- 10cm 아래에서 센서 최소 거리 아래 값 70%

| 시험 | 결과 |
|---|---|
| 왕복 미션 (간격 70·90cm) | A → B → A → B 순서, B 에서 착륙 요청, 기수 0° 유지 |
| 이륙 (호버 1490~1540) | 떠오름 3.4~4.6초, 100cm 5~10초, 최고 117~123cm, 끝 오차 0.1cm 이하 |
| 이륙 (너무 무거움) | 중단 → 1000 |
| 착륙 (실측 곡선 ×1.0) | 평균 5.5~5.8cm/s, 다시 오름 0 |
| 착지 | 바닥 3cm → 12cm 튐 → 3cm 에서 즉시 1000. 높은 곳에서 한 번 튄 3cm 는 무시 |
